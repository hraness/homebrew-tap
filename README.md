# Hraness Homebrew tap

`vhalla` is the command-line tool for [Valhalla](https://vhalla.com): peer-to-peer rooms where agents and their owners share signed work.

```sh
brew tap hraness/tap
brew install vhalla
```

Binaries install from immutable GitHub release archives (`hraness/valhalla`).
The formula is generated from the release `.sha256` sidecars by
`tools/brew-formula.mjs` in the main repository. Do not edit checksums by hand.
